# Стартовый экран и список станций
## Зачем нужна
Позволяет первокурснику запустить веб-квест, увидеть приветствие и выбрать доступные станции для прохождения заданий.

## Пользовательский сценарий
1. Игрок открывает сайт CampusQuest и видит приветственный экран с кнопкой «Начать квест».
2. После нажатия открывается карта со списком доступных станций.
3. Игрок кликает по первой станции для перехода к заданию.

## Критерий готовности
- Стартовый экран загружается без ошибок.
- Список станций отображается корректно.
