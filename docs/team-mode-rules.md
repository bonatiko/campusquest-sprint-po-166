# Правила и ограничения минимального командного режима

## Основные правила
* **Размер команды:** От 2 до 4 игроков.
* **Авторизация:** Вход в команду только по короткому коду.
* **Отправка ответов:** Любой игрок команды имеет право отправить ответ на станции.
* **Подсчёт баллов:** Все баллы идут в один общий счёт команды.

## Исключения из MVP (не входят в релиз)
* Чат между игроками.
* Приглашения по прямой ссылке.
* Разделение на спецроли внутри команды.
* Push-уведомления.
